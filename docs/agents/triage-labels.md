# Triage Labels

Use the canonical role vocabulary as-is; do not invent labels.

| Canonical role | Label in tracker | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer must evaluate this |
| `needs-info` | `needs-info` | Waiting on the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | `ready-for-human` | Needs a human implementer |
| `wontfix` | `wontfix` | Will not be actioned |

A published spec carries `Status: ready-for-agent`; do not re-triage it.
