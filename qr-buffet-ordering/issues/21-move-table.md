# 21: ย้ายโต๊ะ: ย้ายทั้ง session ไปโต๊ะว่าง

Status: ready-for-agent

Source: `../spec.md` (user stories 54) และ `../plan.md` (ไม่มีใน plan.md (ใหม่ตาม spec)); ถ้า spec กับ plan ขัดกัน ให้ยึด spec; หน้าจอที่ออกแบบแล้ว: frame o18 ใน `../../design/out/`

## What to build

เจ้าของร้านเลือก "ย้ายโต๊ะ" จากการ์ดออเดอร์ เลือกโต๊ะปลายทางจากโต๊ะว่างเท่านั้น (โต๊ะที่มีลูกค้าเลือกไม่ได้) ระบบย้ายทั้ง session (ออเดอร์ บิล รายการปรับยอด และเวลานั่ง) โดย QR/token เดิมใช้ได้ต่อ โต๊ะเดิมว่างทันที

## Override ของ plan.md

plan.md บรรทัด 119 ('ย้ายโต๊ะและรวมโต๊ะไม่อยู่ในขอบเขต') ถูกยกเลิกสำหรับการย้ายโต๊ะ (ผู้ใช้ตัดสินให้เก็บ)

## Blocked by

14 คิวออเดอร์ของเจ้าของร้าน

## Acceptance criteria

- [ ] ย้ายไปโต๊ะที่มี session Open → `TABLE_OCCUPIED`; ย้ายสำเร็จแล้ว token เดิมสั่งได้ และเห็นข้อมูลชุดเดิมที่โต๊ะใหม่ (เทสต์ seam 1)
- [ ] โต๊ะเดิมแสดงว่างบนผังทันที และการ์ดครัวแสดงชื่อโต๊ะใหม่ (`sessionChanged`)
- [ ] หน้าตรงกับ mockup o18 (ตัวเลือกโต๊ะปลายทาง สรุปสิ่งที่ย้าย) และเปิดจากปุ่ม "ย้ายโต๊ะ" ใน ticket 14
- [ ] สร้างครบทุกชั้นที่ slice นี้แตะ (schema/API/UI) พร้อมเทสต์ seam 1 ตามหัวข้อ Testing Decisions ของ spec และ smoke run บน stack จริง (`docker compose up`) ที่เห็นพฤติกรรมของ ticket นี้ด้วยตา; โมเดลที่เพิ่มเข้า migration `Initial` ตัวเดียว (ดู ticket 01)
