# 15: ป๊อปอัปออเดอร์ใหม่พร้อมเสียงสำหรับเจ้าของร้านทุกหน้า

Status: ready-for-agent

Source: `../spec.md` (user stories 59) และ `../plan.md` (Step 14 (layout), Step 13 (เสียง)); ถ้า spec กับ plan ขัดกัน ให้ยึด spec; หน้าจอที่ออกแบบแล้ว: frame o20, o21 ใน `../../design/out/`

## What to build

เมื่อมีออเดอร์ใหม่เข้ามา เจ้าของร้านเห็นป๊อปอัปกลางจอบนทุกหน้า owner พร้อมเสียงเตือน ปิดเสียงได้ ป๊อปอัปแสดงโต๊ะ เลขรอบ สรุป และรายการที่ขยายดูได้ มีปุ่ม "ไว้ก่อน" (ปิดป๊อปอัป) และ "ไปหน้าออเดอร์" (นำทางไปคิวออเดอร์ ไม่เริ่มทำที่ป๊อปอัป) ไอคอนกระดิ่งนิ่ง ไม่กะพริบ

## Blocked by

14 คิวออเดอร์ของเจ้าของร้าน

## Acceptance criteria

- [ ] ส่งออเดอร์จากฝั่งลูกค้าขณะ Owner อยู่หน้าใดก็ได้ → ป๊อปอัปขึ้นและเสียงดังหนึ่งครั้ง; ปิดเสียงแล้วไม่ดัง; ปุ่ม "ไปหน้าออเดอร์" นำทางโดยไม่เปลี่ยนสถานะออเดอร์
- [ ] ตรงกับ mockup o20 (ยุบ) และ o21 (ขยายรายการ) บนหน้าผังโต๊ะ; เสียงเล่นหลังการโต้ตอบครั้งแรกของผู้ใช้ตามข้อจำกัดของเบราว์เซอร์ (บันทึกพฤติกรรมไว้)
- [ ] สร้างครบทุกชั้นที่ slice นี้แตะ (schema/API/UI) พร้อมเทสต์ seam 1 ตามหัวข้อ Testing Decisions ของ spec และ smoke run บน stack จริง (`docker compose up`) ที่เห็นพฤติกรรมของ ticket นี้ด้วยตา; โมเดลที่เพิ่มเข้า migration `Initial` ตัวเดียว (ดู ticket 01)
